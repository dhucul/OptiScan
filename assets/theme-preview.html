OptiScan — Theme Preview

Four candidate themes applied to OptiScan's actual role map. Each card mocks the real window: title wordmark, command panel + buttons (with left accent stripe / red Exit variant), console header (dots · READY · spectrum), log-line roles, and a mini BLER-style graph. Edit the hex values in the THEMES object near the bottom of this file and refresh to tune. Nothing here touches the app — this is the "model first" step.

Role notes — accentWarm drives the title "Scan" + command text (graphite = warm tan); accentCool drives panel borders, header dots, spectrum and tech accents (graphite = steel blue). Log heading = ===/--- lines, command = >>> echo, graphBar/graphFrame = box-drawing + block chars. Graph bars are colored green→yellow→red by severity. These are starting values; approve or adjust before I wire the runtime switcher.
